# «Цифра» — лёгкая демо-версия

Отдельный вариант сайта: главная, цены, отправка фото, фотопакет 10×10 и демо-политика.
Без сборки, зависимостей и онлайн-оплаты. Можно открыть на компьютере, на телефоне
в той же Wi-Fi-сети и временно показать снаружи через туннель.

## Запуск на компьютере

Дважды щёлкните `start-v2.cmd` в корне проекта или выполните:

```powershell
node serve-v2.js
```

Сайт: http://localhost:8090

## Открыть на телефоне

1. Подключите телефон и компьютер к одной Wi-Fi-сети.
2. Запустите `start-v2.cmd` — сервер покажет адрес для локальной сети.
3. Откройте этот адрес на телефоне, например: http://192.168.88.88:8090

Если страница не открывается:

- разрешите Node.js доступ к сети в брандмауэре Windows;
- проверьте, что телефон не в VPN и в той же сети, что компьютер;
- адрес может измениться после перезагрузки роутера — смотрите новую строку в окне сервера.

Остановка сервера: `Ctrl+C` или закрыть окно.

## Показать снаружи (для демонстрации)

Быстрый вариант без хостинга и регистрации — временный туннель localtunnel.

1. Запустите `start-online-demo.cmd` в корне проекта.
2. Скрипт поднимет локальный сервер (если он ещё не запущен) и покажет строку вида `your url is: https://...loca.lt`.
3. Отправьте эту ссылку владельцу. Она работает, пока открыто окно туннеля и включён компьютер.
4. Остановить туннель можно через `stop-online-demo.cmd` или закрыв окно `start-online-demo.cmd`.

Важно:

- Это временная ссылка для показа, а не публикация сайта.
- Ссылка каждый раз новая; после закрытия окна туннеля она перестаёт работать.
- localtunnel может быть недоступен из некоторых сетей. Если ссылка не открывается, попробуйте VPN или другой туннель.
- Форма отправки фото остаётся демо. Фотопакет сохраняет файлы в локальную папку на компьютере, оператору они не уходят. История заявок — в браузере посетителя.

## Публикация на GitHub Pages

Для показа владельцу сайт можно бесплатно выложить на GitHub Pages.

1. Создайте публичный репозиторий на GitHub.
2. Загрузите в корень репозитория содержимое папки `site-v2`: `index.html`, `tseny.html`, `otpravit-foto.html`, `foto-paket.html`, `politika.html`, `stili.html`, `404.html`, папку `assets` и файл `.nojekyll`.
3. Откройте Settings → Pages → Build and deployment.
4. Выберите Source: Deploy from a branch, Branch: `main`, folder: `/ (root)`, нажмите Save.
5. Через 1–2 минуты сайт будет доступен по адресу `https://USERNAME.github.io/REPOSITORY/`.

Важно:

- На бесплатном тарифе репозиторий должен быть публичным — код и файлы будут видны.
- GitHub Pages отдаёт только статику: форма отправки фото останется демо-режимом.
- Папка `storage` с демо-заказами не публикуется: `publish-demo.cmd` исключает её, в `.gitignore` она тоже закрыта.
- Для демо в страницах включён `noindex`; для публичного сайта его нужно убрать.
- `404.html` GitHub Pages показывает для любого несуществующего адреса. В нём есть скрипт, который подставляет `<base>` для адресов вида `/REPOSITORY/a/b`, иначе относительные стили не загрузились бы.
- Свой домен подключается в Settings → Pages → Custom domain.
- Для постоянного сайта в России лучше российский хостинг: он даст рублёвую оплату, поддержку и нормальную работу с заявками.

## Цены

- `tseny.html` — печать фотографий, документы, копирование, цифровые услуги, ретушь, ламинация, брошюровка, холст, полиграфия и сувениры.
- На компьютере цены собраны в 2–3 колонки, на телефоне — в одну.
- Кнопка «Офисы и телефоны» ведёт к карточкам офисов на главной.
- Цены перенесены с прайса от 01.01.2026; перед публикацией их нужно подтвердить у владельца.

## Фотопакет 10×10

- `foto-paket.html` — пакеты на 12, 24 или 36 квадратных фото 10×10 см.
- Фото выбираются с диска или перетаскиваются; на телефоне можно выбрать из галереи.
- Каждое фото сразу показывается в квадратной рамке. Кадр по умолчанию центрирован, его можно сдвигать, масштабировать колесом/щипком и сбрасывать кнопкой «По центру».
- В сетке видны номера, предупреждение о низком разрешении и кнопка удаления.
- Заказ демонстрационный: оператору ничего не уходит.
- При локальном запуске через `node serve-v2.js` после заказа файлы сохраняются в `site-v2/storage/orders/ГГГГ-ММ-ДД/CIFRA-…/`: `01.jpg…`, `order.json` и строка в `storage/orders.csv`. Это имитация продакшена, папка исключена из публикации.
- На GitHub Pages папка выбирается через File System Access API (Chrome/Edge). Если API нет — скачивается ZIP с той же структурой `storage/orders/…`.
- Режим сохранения можно форсировать для проверки: `?demoSave=server`, `?demoSave=folder` или `?demoSave=zip`.
- В localStorage сохраняются только номер, дата, размер пакета, цена и офис — без имени, телефона и фотографий.
- Цены пакетов (590 / 1 090 / 1 490 ₽) — демонстрационные, перед публикацией их нужно подтвердить у владельца.
- В боевой версии `site-prod/foto-paket.html` те же кадры собираются в JPEG 1200×1200 и уходят в `send.php`.

## Важно

- Это демо-макет; временная внешняя ссылка нужна только для показа.
- Форма отправки фото работает только в браузере: файлы никуда не загружаются. Обезличенная история заявок (номер, дата, услуга, офис, формат, количество файлов и их общий размер) сохраняется в localStorage на 14 дней; имя, телефон и файлы не сохраняются.
- Фотопакет — исключение: он сохраняет JPEG и `order.json` в `site-v2/storage/orders/…`. В `order.json` есть имя и телефон, как в продакшене, поэтому папку `storage` нельзя публиковать и коммитить. `publish-demo.cmd` и `.gitignore` её исключают.
- История заявок привязана к адресу сайта в браузере. При смене временной ссылки localtunnel она не переносится; для проверки истории перезагружайте ту же ссылку.
- Порт по умолчанию — `8090`. Если он занят, задайте другой:
  ```powershell
  set PORT=8091
  node serve-v2.js
  ```
- Сервер слушает локальную сеть (`0.0.0.0`). Не открывайте этот порт в интернет.
